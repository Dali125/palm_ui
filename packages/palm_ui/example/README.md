# Palm UI Example App

This example project is an interactive showcase application exhibiting every widget, theme preset, and mobile pattern provided by `palm_ui`.

## What's Included

- **Theme Switching**: Toggle seamlessly between Semantic Light mode, Semantic Dark mode, and Android Material You dynamic color extraction (`PalmUIDynamicThemes`).
- **Live Search**: Instant keyword search and filter across all 50+ components.
- **Categorized Component Showcases**:
  - **Inputs & Buttons**: `PalmUIButton`, `PalmUIButtonGroup`, `PalmUIFab`, `PalmUIToggle`, `PalmUIToggleGroup`.
  - **Forms & Controls**: `PalmUIInput`, `PalmUIField`, `PalmUILabel`, `PalmUITextarea`, `PalmUIInputGroup`, `PalmUIInputOtp`, `PalmUICheckbox`, `PalmUISwitch`, `PalmUISlider`, `PalmUIRadioGroup`, `PalmUISelect`, `PalmUICombobox`.
  - **Data Display**: `PalmUICard`, `PalmUIBadge`, `PalmUIAvatar`, `PalmUITable`, `PalmUIDataTable`, `PalmUICarousel`, `PalmUIListTile`, `PalmUIItem`, `PalmUIKbd`.
  - **Feedback**: `PalmUIAlert`, `PalmUIToaster` / `PalmUIToastCard`, `PalmUIProgress`, `PalmUISpinner`, `PalmUISkeleton`, `PalmUIEmpty`.
  - **Overlays**: `PalmUIDialog`, `showPalmUIDialog`, `PalmUIAlertDialog`, `showPalmUIAlertDialog`, `PalmUISheet`, `showPalmUISheet`, `PalmUIDrawer`, `showPalmUIDrawer`, `PalmUIPopover`, `PalmUIHoverCard`, `PalmUITooltip`, `PalmUICommand`.
  - **Menus**: `PalmUIDropdownMenu`, `PalmUIContextMenu`, `PalmUIMenubar`.
  - **Navigation**: `PalmUIAppBar`, `PalmUIBottomNav`, `PalmUITabs`, `PalmUIBreadcrumb`, `PalmUIPagination`, `PalmUINavigationMenu`, `PalmUISidebar`.
  - **Disclosure**: `PalmUIAccordion`, `PalmUICollapsible`.
  - **Pickers**: `PalmUICalendar`, `PalmUIDatePicker`.
  - **Layout & Typography**: `PalmUISeparator`, `PalmUIScrollArea`, `PalmUIAspectRatio`, `PalmUIText`.

## Running the Example

Run on a connected mobile device, tablet, desktop, or simulator:

```bash
cd example
flutter run
```
